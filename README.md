# gromacs-md-protocols
Reproducible GROMACS 2023.3 (CUDA) workflows for protein–protein complexes and protein–ligand systems. Includes ready-to-use .mdp files, step-by-step guides, APO vs HOLO analysis (RMSD, RMSF, Rg, SASA, BSA, H-bonds), MM/GBSA with gmx_MMPBSA, and a Python plotting script for publication-ready figures.
